# v18 Home context menus

- Home app long-press now uses the home-specific menu: app info, gesture status, edit icon entry, rename, and remove icon.
- Removing an app icon hides it only from the Home layout; it does not hide or uninstall the app. Re-adding it from the desktop Add App flow restores it.
- Search-result long-press menu remains unchanged.
- Home widgets now support long-press selection with a selection outline/handles and a widget menu: Configure, Fine tune, Remove widget.
- Fine tune currently persists widget height (96–320dp).
- Configure opens the widget provider's configuration Activity when one exists.
