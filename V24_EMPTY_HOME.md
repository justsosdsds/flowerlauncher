# V24 — Empty Home

- Home is now empty by default.
- Existing Home app icons, folders, widgets, clock, and bottom search bar are cleared once when upgrading to v24.
- Installed apps are no longer auto-populated onto Home.
- Only apps/folders/widgets explicitly added by the user appear on Home afterwards.
- Home swipe gestures, empty-area long press, Search, App Drawer, and Settings remain available.
