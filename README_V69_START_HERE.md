# V69：保持抽屉不变，搜索模糊对齐抽屉

基线为上一版交付的 V68。唯一修改的已有源码文件是 `app/src/main/java/com/flower/launcher/ui/LauncherRoot.kt`。

## 变化

- 搜索背景不再随着进入进度降到 84% 不透明度，固定 `alpha = 1f`，避免底层清晰壁纸透入模糊层。
- 搜索背景不再额外缩小到 98.8%，使用与抽屉相同的 `scaleX = editScale`、`scaleY = editScale`，保持原有桌面编辑缩放；普通搜索/抽屉状态下为 1。
- 搜索背景的位移和变换中心与抽屉保持一致：`translationY = 0f`、`TransformOrigin.Center`。
- 搜索返回时移除独立的模糊退场曲线，按当前进度调用抽屉原有的 `composeBlurLevel`。相同绝对进度选择同一档缓存；没有改动该函数、模糊强度或缓存纹理。
- 搜索前景的位移、缩放、淡出、返回动画保留。

抽屉的模糊映射分支、背景 graphicsLayer 分支以及整个抽屉页面渲染/交互区块均与 V68 字节一致。AllAppsContent、SearchContent、手势协调器、缓存构建和壁纸来源等文件均未修改。没有改变抽屉的模糊强度、遮罩或动画。

## 验证结果与限制

- 对比全部已有文件：仅 LauncherRoot.kt 发生变化。
- 抽屉模糊分支、背景分支和完整页面区块：字节一致。
- 搜索前景动画区块：字节一致。
- 共用模糊函数：字节一致。
- 原有 V61 手势协调器源码检查：12 项通过。
- 编译/安装/真机视觉未验证。之前的 Gradle 下载被环境网络限制阻断，本轮没有把源码检查当作编译或视觉通过。

验收时，在同一壁纸、同一模糊设置下，分别完全打开抽屉和搜索，对比前景控件以外的背景区域；再检查两页进入/返回时相同绝对进度的模糊档位。抽屉应与 V68 保持一致，搜索不应再混入底层清晰壁纸或在返回时切换到另一套背景合成规则。

V68 的平台限制仍适用：系统壁纸模式只能透明显示真实系统壁纸；需要让壁纸本身进入模糊缓存时，须选择图片作为桌面背景，且 Gaussian Blur 适用于 Android 12 / API 31 及以上。控件、壁纸源、缓存生命周期的其他说明参见 README_V68_START_HERE.md。
