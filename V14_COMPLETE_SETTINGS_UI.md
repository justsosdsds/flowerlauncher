# v14 - Complete Settings UI

This version expands the FlowerLauncher settings UI using the recovered Smart Launcher settings tree as a structural specification.

## Added settings pages
- Home
- Apps page
- Search page
- Gestures & hot keys
- Global appearance
- Dark mode
- Icon appearance
- Wallpaper
- Notifications
- Folders
- Widgets
- Dock
- Category bar
- Screen
- Security & privacy / hidden apps
- Backup & restore
- Page manager
- Multi-display
- Your Feed
- Troubleshooting
- Experimental options
- Version info

## Behavior
Existing FlowerLauncher features remain interactive. Recovered settings that do not yet have a FlowerLauncher implementation are shown as `待实现` rather than fake controls.

Search settings continue to use the existing functional SearchSettingsScreen.
